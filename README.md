

This repository contains the assignments and practical exercises completed as part of the Agile and Scrum training.

The assignments cover the following topics:

Agile Methodology

Scrum Roles, Events and Artifacts

User Stories and Product Backlog

Story Estimation and Planning Poker

Sprint Planning and Sprint Simulation

Agile and DevOps / CI-CD Culture

Agile in Distributed and Remote Teams

Agile Practical Assessment and Interview Preparation

The assignments are based on real-world scenarios to practise Agile concepts, Scrum activities, backlog creation and sprint management using Jira.
